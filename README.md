# Customer Churn Prediction Application

## Overview

This folder contains the Streamlit-based interactive application developed for the Customer Churn Prediction Using Machine Learning project.

The application provides a user-friendly interface that allows users to input customer information and receive machine learning-based churn risk predictions.

The application demonstrates how predictive analytics can support customer retention strategies by identifying customers with a higher likelihood of churn.

## Application Features

The Streamlit application:

- Collects the required customer features used by the trained machine learning model.
- Processes customer inputs using the trained preprocessing pipeline.
- Calculates the predicted probability of customer churn.
- Applies the optimized classification threshold of 0.57 to determine churn status.
- Assigns customers into risk categories:
  - Low Risk
  - Moderate Risk
  - High Risk
  - Very High Risk
- Provides predictive insights that can support customer retention prioritization.

## Machine Learning Integration

The application uses the trained machine learning pipeline, including:

- Data preprocessing components
- Feature transformation processes
- Gradient Boosting classification model
- Risk classification logic
- Model metadata and validation information

The system ensures that user inputs follow the same feature structure used during model development.

## Intended Use

This application demonstrates the practical application of machine learning for customer churn prediction and decision support.

The predictions generated by the system are intended to assist analysts and business teams in identifying customers who may require further review and retention consideration.

The application should not be used as the sole basis for customer decisions without additional validation using real-world customer data and appropriate human oversight.

The application showcases how machine learning models can be transformed into interactive tools that allow organizations to apply predictive insights in practical business environments.
