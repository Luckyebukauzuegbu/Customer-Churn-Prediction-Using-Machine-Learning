# Dataset

## Overview

This folder contains the customer dataset used for the Customer Churn Prediction Using Machine Learning project.

The dataset represents customer information within a banking environment and is used to develop predictive models for identifying customer churn patterns and analysing factors associated with customer retention.

The dataset contains structured customer attributes covering demographic characteristics, financial information, transaction behaviour, customer engagement, service experience, and account-related variables.


## Main Dataset

`nigeria_bank_churn_dataset.csv`

The dataset contains:

- 15,000 customer records
- 48 variables
- Customer demographic information
- Financial and account characteristics
- Transaction behaviour indicators
- Customer engagement features
- Churn classification outcome (`Churn_Within_6M`)

## Dataset Purpose

The dataset supports the development and evaluation of machine learning models for:

- Customer churn prediction
- Classification modelling
- Predictive analytics
- Customer risk segmentation
- Feature importance analysis
- Data-driven customer retention strategies
